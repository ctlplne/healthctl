# Feedback and bug reports

healthctl is a ctlplne studio product. The maintainer welcomes usability feedback, documentation corrections and bug reports through GitHub issues. Describe the version, what you tried, and what you expected using invented details. The project currently accepts code and commits only from its maintainer, @imfeelingtheagi.

For a possible security or patient-safety problem, use the private route in [SECURITY.md](SECURITY.md). Keep patient information, recordings, real encounter screenshots and credentials out of issues, private reports and pull requests.
