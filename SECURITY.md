# Report a security or patient-safety defect

Use [private reporting on GitHub](https://github.com/ctlplne/healthctl/security/advisories/new) to tell the healthctl maintainer about a suspected security issue, unintended disclosure, or behavior that could harm someone. A missed urgent warning, a warning lost in an export, or an outdated estimate presented as current belongs here even if you see no security vulnerability. For a safety-only report, start the title with “Clinical safety” and leave vulnerability identifiers empty.

Send the version or commit, installation path, steps with invented inputs, and the expected and observed behavior. Use a fictional example even in the private form. Never attach real patient records, recordings, screenshots of real encounters, database backups, access tokens or credentials. A report is voluntary. The app cannot send one on your behalf.

The repository maintainer handles triage for ctlplne studio, reproduces the report using synthetic data, and coordinates a fix or affected-build notice. Use a public issue only for ordinary feature requests and fictional, non-sensitive bugs. This channel does not provide medical care or emergency monitoring. For a possible emergency, seek local emergency care immediately.
